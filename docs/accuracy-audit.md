# 耗时公式与准确性审计

日期：2026-10-23。本文区分实际计时、模型内部数学正确性和真实任务预测精度；测试通过不能代替真实日志上的预测验证。

## 1. 实际已用时是观测

hook 在宿主接受任务和终结任务时读取同一个单调时钟：

\[
T_{\mathrm{elapsed}}(t)=t_{\mathrm{monotonic}}-t_{\mathrm{start}},\qquad
T_{\mathrm{actual}}=t_{\mathrm{end}}-t_{\mathrm{start}}.
\]

这测量的是两个 hook 之间的真实时间间隔，包括等待。精度取决于时钟分辨率、宿主事件发出的时机和界面刷新频率；它不是未来耗时预测。开始、完成、取消、失败事件必须来自宿主真实生命周期，不能把普通聊天当作任务。

## 2. 条件模型及精确矩

现有 v1 是串行工作量模型。给定任务特征 \(g\) 和任务类别 \(C=c\)：

\[
N_j\mid C=c,g\sim\operatorname{Poisson}(\lambda_{jc}),\quad
\lambda_{jc}=\exp\{\operatorname{clip}(b_j+w_j^\mathsf{T}g_c,-20,20)\},
\]
\[
X_{ji}\sim\operatorname{LogNormal}(\mu_j^{\text{eff}},s_j^2),\quad
s_j^2=\sigma_j^2\max(\phi,1),\quad
\mu_j^{\text{eff}}=\mu_j-\tfrac{s_j^2-\sigma_j^2}{2},\quad
T=\sum_j\sum_{i=1}^{N_j}X_{ji}.
\]

φ 是保均值的离散度：σ 放大多少，对数均值就下移一半的增量，因此 \(E[X_j]\) 与 φ 无关。
假设给定类别后各操作类型相互独立、步长独立同分布且独立于步数，所有步骤串行且互不重叠。参数和类别权重在一次预测中固定。对数正态的矩为：

\[
E[X_j]=e^{\mu_j+\sigma_j^2/2},\qquad E[X_j^2]=E[X_j]^2e^{s_j^2}=e^{2\mu_j+\sigma_j^2+s_j^2}.
\]

由条件期望和全方差公式，复合泊松满足：

\[
E\!\left[\sum_{i=1}^{N_j}X_{ji}\right]=\lambda_{jc}E[X_j],
\]
\[
\operatorname{Var}\!\left(\sum_{i=1}^{N_j}X_{ji}\right)
=E[N_j]\operatorname{Var}(X_j)+\operatorname{Var}(N_j)E[X_j]^2
=\lambda_{jc}E[X_j^2].
\]

因此给定类别的精确矩是：

\[
M_c=\sum_j\lambda_{jc}e^{\mu_j+\sigma_j^2/2},\qquad
V_c=\sum_j\lambda_{jc}E[X_j]^2e^{s_j^2}.
\]

“精确”指在上述假设及固定参数下代数成立，不表示真实 Agent 一定符合这些假设。步长与步数相关时，最后一项等式一般不成立。

## 3. 类别混合修正

top-2 权重在选中的两个类别内归一化为 \(p_c\)。当前实现先除最大权重再求和，避免两个有限大权重的和溢出。只保留 top-2 本身仍是近似，分类器提供的权重也不自动等于真实类别概率。

完整混合分布及其矩为：

\[
F_T(t)=\sum_cp_cF_{T\mid c}(t),\qquad M=\sum_cp_cM_c,
\]
\[
\operatorname{Var}(T)=\underbrace{\sum_cp_cV_c}_{\text{类别内方差}}
+\underbrace{\sum_cp_c(M_c-M)^2}_{\text{类别间方差}}.
\]

旧实现把 \(\sum_cp_c\lambda_{jc}\) 当作一个泊松率采样，只保留平均步数，丢失类别间方差及共享任务类别造成的操作间相关性。现改为每条模拟路径先抽一次类别，所有操作类型共享这个类别；随后按该类别抽步数和步长。加权平均率仅用于期望和贡献分解。运行时、离线校准及验收使用同一个采样入口。

独立可手算例子：四类操作每步固定 1 秒；patch 的各类率为 1，debug 的各类率为 9，两类各占一半。则 \(T\mid patch\sim Pois(4)\)，\(T\mid debug\sim Pois(36)\)：

\[
E[T]=20,\quad E[\operatorname{Var}(T\mid C)]=20,\quad
\operatorname{Var}(E[T\mid C])=256,\quad\operatorname{Var}(T)=276.
\]

旧平均率采样的方差只有 20，独立复现实测约 20.235。新测试同时检验均值、方差和 \(P(T\le10)\) 接近一半，防止只改均值或为每类操作各抽一次类别的错误。

## 4. 相对不确定度与分位数

给定类别、期望大于零时：

\[
\operatorname{CV}^2(T\mid c)=
\frac{\sum_j\lambda_{jc}e^{2\mu_j+2s_j^2}}
{\left(\sum_j\lambda_{jc}e^{\mu_j+s_j^2/2}\right)^2}.
\]

只有各类步长服从同一分布时才能化简为：

\[
\operatorname{CV}(T\mid c)=\frac{e^{s^2/2}}{\sqrt{\sum_j\lambda_{jc}}}.
\]

原设计的 \(e^\sigma/\sqrt{\bar n}\) 不正确；仅“标准差相近”也不足以化简。类别混合还需加入类别间方差，不能凭步骤多就保证区间更窄。

P50、P90 用默认 5000 条路径的蒙特卡洛分位数近似，没有通用的闭式分位数公式。固定种子只保证复现，不消除采样误差；分位数的秒数误差还取决于该处密度、尾部和原子概率。P50–P90 不是 90% 概率区间；在连续、已校准的预测分布下它约包含 40% 概率。

## 5. 零步骤原子与校准修正

复合泊松不是处处连续的分布：

\[
P(T=0)=\sum_cp_c\exp\!\left(-\sum_j\lambda_{jc}\right).
\]

因此直接检验 \(F_T(T)\) 是否均匀会误拒绝含明显零步骤概率的正确模型。现对每个实际观测及其独立预测样本使用随机化预测秩：

\[
U_{\mathrm{rank}}=
\frac{\#\{S_i<y\}+u\left(\#\{S_i=y\}+1\right)}{m+1},\quad
u\sim\operatorname{Uniform}(0,1).
\]

当 \(y,S_1,\ldots,S_m\) 是独立同分布抽样时，实际值在包含并列值的样本中随机排序，并在对应秩区间内均匀抖动，得到均匀分布。\(u\) 使用独立于预测采样的种子流；固定总种子可复现。

分位数验收也使用一般判据 \(P(Y<q_\tau)\le\tau\le P(Y\le q_\tau)\)，在经验比例上加现有容差。报告保留 `coverage = mean(actual <= q)`，新增 `coverage_below = mean(actual < q)`；在有原子时不再强求前者等于名义水平。连续分布下两者相同，恢复原双侧判据。KS 的有限样本 p 值和这套两倍标准误容差仍是近似的统计判据，不能证明模型为真。

回归例子：四类操作各 \(\lambda=.1\)，则 \(P(T=0)=e^{-.4}\approx .6703\)，P50 为 0，正确的 P50 上限覆盖率可以超过 0.6。测试独立生成总步数 \(Pois(.4)\) 及步长，确认正确模型可通过校准，同时保留过度自信模型必须被拒绝的测试。

## 6. 尚未解决的预测边界

- **phi 是离散度，不是万能修正。**φ 现在只放大步长对数方差（保均值），并由留出残差的平均相对平方误差**解析求出**：
  模型相对方差对 φ 是单调的指数和（类别间方差与 φ 无关，作为常数项保留），因此二分求根即可，
  内点解处"解析 CV² = 残差均方"精确成立；φ 仍夹在 `[1,25]`，无残差噪声时回到 1。
  它修正的是离散度，**不**修正偏差（均值偏移由计数回归与步长位置吸收），也**不**恢复重试相关性；
  若模型均值本身就错了，φ 只会把错的东西摊得更宽。必须由留出数据检验最终分布，不能声称区间已被修好。
- **未完整积分参数不确定性。**NIG 用于步长参数收缩，预测仍使用参数点估计；计数回归参数及分类权重的不确定性也没有完整后验传播。
- **取消可能带来选择偏差。**v1 保留取消前已完成的步骤，但取消若与耗时相关，这些完整步骤也不保证无偏；未完成步骤只有下界。当前没有完整的生存/删失模型。
- **串行求和不等于任意任务的 wall time。**重叠工具调用、嵌套计时、并行分支、未记录的排队与等待都可能失配。一个子任务只能被计入一次；LLM、工具、构建和网络的时间边界需由宿主定义清楚。
- **并行任务需要执行图。**若依赖 DAG、节点实际时长和等待都已知，资源争用已被编码，则节点完成时间为 \(f_v=d_v+\max_{u\in pred(v)}f_u\)，空前驱最大值取 0；总时间为终点完成时间的最大值，即关键路径。未知节点时长时要传播联合分布，\(E[\max(A,B)]\) 一般不等于 \(\max(E[A],E[B])\)。本次没有凭空新增一个无真实遥测支撑的 DAG 引擎。
- **环境和行为会变化。**模型、机器、缓存、限流、故障重试、任务分类错误和用户中断都能改变未来耗时。不存在从当前有限信息中无条件精确预知所有 Agent 任务完成时刻的公式。

## 7. 证据与展示门控

`tests/test_math_audit.py` 检验独立闭式矩、采样、混合及离线一致性。例如单操作 \(N\sim Pois(3),\mu=\ln2,\sigma^2=\ln2\) 时，均值为 \(6\sqrt2\)、方差为 48；phi=2 时均值仍为 \(6\sqrt2\)、方差变为 96（φ 只动二阶矩）。另用 100000 条独立模拟路径核对采样矩。`tests/test_math_upgrade.py` 覆盖保均值 φ、φ 的解析求根、秩分位数区间、NIG 数值稳定性与 IRLS 收敛；`tests/test_calibrate.py` 覆盖零步骤原子及错误分布拒绝，hook/TUI 测试覆盖未校准隐藏预测带。推导与量化结果见 [math-upgrade.md](math-upgrade.md)。

截至本次审计，仓库没有真实任务 `data/` 日志，已有 `out/demo/` 记录为合成遥测。历史 P90 覆盖率 0.8873 只是合成验收结果，不能作为真实 Agent 的准确率，也不是本次数学变更后的新成绩。

运行时未校准时，组件仅显示真实已用时及“校准中”，`band=None`、`over_estimate=False`。底层原始先验结果保留用于诊断，不对用户呈现为已验证预测。普通聊天不创建任务；短任务在门槛前隐藏。

获得真实日志后，应按同一模型、同一宿主分组，按时间切分训练与独立留出任务；保存每个任务开始时的预测，分别报告 P50/P90 上限覆盖率及不确定性、随机化 PIT/KS、配对 pinball、各任务类别与并行方式的误差和漂移。不能反复挑选同一留出集来宣称泛化能力。不合格时继续校准并抑制未经验证的时间承诺；不能用合成测试通过代替这一步。
