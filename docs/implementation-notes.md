# v1 实施说明

依据：[设计文档](design.md)。实际实现以设计文档的数据边界和统计定义为准；早期草稿中的示例存在下列可复现问题，已修正并补充回归测试。

| 位置 | 修正与原因 |
|---|---|
| Task 2 时长断言 | `100 → 101.5` 是合法步骤，异常用例改为结束不晚于开始。拒绝非有限时间，跨 schema 事件不参与拟合。 |
| Task 3 top-2 | 只归一化选中的两个概率，拒绝负数与非有限权重；原示例会把第三个概率计入分母。 |
| Task 5 phi | 展宽对复合和的低分位数不保证单调。v1.1 起 φ 改为保均值离散度（`ConstTable.log_params`），均值不动、方差与高分位数上升。 |
| Task 7 合成数据 | 隐藏 sigma 避开与先验恰差 0.05 的浮点边界；总时长从已落盘端点求和，避免微秒舍入造成不一致。 |
| Task 9 泄漏测试 | 先拟合原始记录，再修改 `g_final` 比较；原示例两份列表引用同一对象，无法检测泄漏。零步骤完整任务保留为零计数。 |
| Task 10 校准 | 取消任务只有用时下界，不进入 PIT/覆盖率；修复 pinball 均值被多除一次 2。 |
| Task 11 验收 | 规范门槛是总数 ≥80、拟合 ≥60、验证 ≥20。删除示例误加的“验证也 ≥80”；候选内部过滤验证步骤，避免数据泄漏；小样本切分不使用负索引。 |
| Task 12 离线命令 | 补齐新增观测 ≥50 的触发检查、缺口报告、描述性校准、按时间及环境隔离、实际调用折扣权重；拒绝不重写已有常数及备份。 |
| Task 12 漂移 | 单项 2σ 会在长尾长序列上误报；改为 log1p 后最近 100 项 EWMA，连续两次超过稳定基线 2σ。测试覆盖稳定长流和有限延迟报警。 |
| Task 13 徽章 | 测试的 37 个任务不满足 ≥40 的退出门槛，改为 40，保留生产判据。 |
| Task 13 复盘 | 实际耗时是观测点，不伪造一个相邻区间；坐标轴包含超出预测带的落点。P90 成绩单使用上限覆盖措辞，避免把 P50–P90 带声称为 90% 概率带。补齐贡献条与分类误差表。 |

运行时仍只依赖 numpy；没有安装包或新建环境。真实语义分类、真实遥测适配和分类模型的独立资源配额属于宿主集成边界。

## 2026-10-23 宿主内展示增量

用户修正了交付形态：组件应在宿主 TUI / UI 中直接显示，由用户安排任务的 hook 触发，普通聊天和短任务隐藏。增量规范见 [嵌入组件设计](embedded-widget.md)，接入见 [integration.md](integration.md)。

- `ElapsedHooks` 持有会话任务状态和单调时钟，后台调用原有纯函数 `estimate_task`，不阻塞主 Agent。它是新增的有状态适配层，原有数学层仍无状态且无 I/O。
- `DisplayPolicy` 默认 60 秒。冷启动先验的特征系数为零，不能据此判定长短；采用宿主显式长任务标记、已校准 P50 和实际用时兜底三种触发。
- `render_tui` 返回可挂入宿主布局的文本块；原生 UI 直接绑定 `WidgetState`；`agent_elapsed.bridge` 提供常驻标准输入输出协议。组件没有网页或 HTTP 服务，原有离线 HTML 仅用于统计复盘。
- `presentation.py` 统一运行时与离线报告的整数区间文案。组件只展示预估与已用时，不声称已实现真实进度或剩余用时模型。
- 开始、完成、取消、失败及并行任务均有生命周期覆盖；预估失败保留计时，迟到结果不能恢复已经结束的任务。未绑定任何特定宿主的内部 API。
- 独立代码审查后的回归覆盖：开始时复制概率对，避免排队估算受宿主后续修改影响；发布序号阻止回调重入后继续投递旧状态；回调内关闭不等待线程，避免锁与 join 循环；过深 JSON 按单条输入错误处理，不终止桥进程。

## 2026-10-23 交付纠正与数学审计

用户明确组件本身不应有网页。本轮新增的 Web 自定义元素、HTTP 宿主、网页示例及对应测试已删除；通用 hook、状态协议及 TUI 嵌入方式保留。未校准时 `band=None`、`over_estimate=False`，只展示真实已用时及校准状态。

- 旧类别混合把加权平均率送入单个泊松分布，丢失类别间方差。改为一条任务路径共享一个类别抽样，运行时和离线校准使用同一分布；解析矩及 phi 分母均加入类别间方差。可手算回归例总均值为 20、总方差为 276，而非平均率模型的 20。
- 修正原设计的 CV 简化式：各操作步长服从同一分布且给定类别时为 `exp(sigma_used²/2)/sqrt(sum(lambda))`，一般异质步长需完整二阶矩。
- 分类权重先除最大值再归一化，避免有限大权重求和溢出导致全零概率。
- 复合泊松在零处有原子。校准改为含并列值随机排序的预测秩，分位数门检查 `P(Y<q) <= tau <= P(Y<=q)`，不再错误要求离散上限覆盖率等于名义水平。原始经验 CDF 接口仍仅作诊断。
- phi 的求解与语义在 v1.1 升级为"保均值离散度 + 单调解析求根"，内点解处解析 CV² 与留出残差均方精确相等；它仍只修离散度，不修偏差、不恢复重试相关性。参数后验、真实并行执行图和任务相关性没有被完整建模。数学推导、独立验证、真实数据缺口见 [accuracy-audit.md](accuracy-audit.md) 与 [math-upgrade.md](math-upgrade.md)。

## 2026-10-23 数学升级（v1.1）

不改变分布族、串行求和假设、蒙特卡洛分位数与种子语义，只改公式的求值与求解方式：

- **φ 保均值**：`log_params` 把 σ 的放大与 μ 的下移绑在一起，`E[X]` 与 φ 无关，
  采样与闭式矩共用同一入口。预测均值不再随 φ 漂移。
- **φ 解析求根**：模型的平均相对方差对 φ 是单调指数和（类别间方差作为与 φ 无关的常数项），
  二分求根使内点解精确匹配留出残差，`[1,25]` 仍为夹取边界。
- **步长矩一次求值**：`E[X²]=E[X]²·exp(s²)`，非有限值直接报错；`task_moments` 不再按类别重算步长矩。
- **分位数带不确定度**：秩区间（二项精确反解）给出 `p50_ci/p90_ci/p50_se/p90_se`，
  原子处自然退化，不需要密度估计。
- **IRLS**：加权初值、对角惩罚、Cholesky（失败再抖动、再 lstsq）、梯度收敛判据、相对目标容差；
  截距不受惩罚的得分方程 Σλ̂=Σŵy 与"读 g_final 即泄漏"的守卫保持不变。
- **损失单一来源**：`calibrate.interval_loss` 同时供门禁与漂移使用；`gate.evaluate` 追加
  `paired_diff/paired_diff_se/paired_z` 与可选 `min_effect`（默认 0，判据与旧版等价）。

逐条推导、量化的验证结果和"明确没有做什么"见 [math-upgrade.md](math-upgrade.md)。
